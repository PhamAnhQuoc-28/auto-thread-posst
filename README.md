# auto-thread-posst

## Setup lần đầu

1. Install Node.js
2. npm install
3. npx playwright install chromium
4. Double-click login.bat
5. Login Threads manually
6. Close browser

## Sử dụng

- Sửa danh sách bài viết trong `data/posts.json`
- Chạy `post.bat` để đăng bài tự động. Mỗi lần chạy công cụ sẽ đăng 1 bài viết có trạng thái là `pending`.
